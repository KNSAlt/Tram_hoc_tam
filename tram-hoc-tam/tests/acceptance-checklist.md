# MVP acceptance checklist

## Content safety
- [ ] Resource without verified source/license cannot be published.
- [ ] Full-book scan is blocked or routed to legal review; it is never auto-published.
- [ ] Every published resource keeps source and license metadata.

## Temporary session
- [ ] A transition session requires `startsAt` and `expiresAt`.
- [ ] Student view hides expired transition resources.
- [ ] Admin can close a session manually when all students receive SGK.

## Book circulation
- [ ] A book copy cannot be loaned to two active groups at the same time.
- [ ] Returned books become available immediately.
- [ ] Location and status are visible to staff.

## Privacy
- [ ] Demo environment uses synthetic student data only.
- [ ] Student profiles contain only the minimum fields required for the workflow.
- [ ] Audit log records publish/delete/review/close actions.

## Paper-first fallback
- [ ] Teacher can print a lesson sheet without any special device requirement.
- [ ] Student can complete a lesson without personal Internet access.
